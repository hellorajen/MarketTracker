# NetGanesh Global Macro & Multi-Asset Investor Matrix Engine

An automated Python-based PDF generation engine built with **ReportLab** and **yfinance**. It creates a comprehensive, publication-grade 24-page landscape calendar matrix and weekly macro trend analysis tracking global equities, treasuries, commodities, and currencies.

## Features
* **12-Month Calendar Matrix:** A side-by-side daily view mapping US indices (S&P, Dow, NASDAQ, 10-Year Treasury) alongside key commodities and currencies (Gold, Oil, USD/INR, USD/JPY) with color-coded performance indicators and official exchange holiday schedules.
* **Faint Watermark Layout:** Clean daily grid formatting with background date watermarks and top-aligned financial metrics.
* **Weekly YTD Trend Charts:** Built-in vector line charts sampling weekly closing data across 52 points, highlighting NASDAQ and Gold trajectories.
* **Automated PDF Compilation:** Generates a complete, ready-to-distribute multi-page investor report.

## Tech Stack
* **Python 3.10+**
* **ReportLab** (PDF Layout & Vector Graphics)
* **yfinance** (Market Data Retrieval)
* **Holidays** (Regional Exchange Calendars)
